## Setup System

* Write your ip on vite.config.js(line 15)
```bash
host: 'your_ip'
```

* Generate encryption key
```bash
php artisan key:generate
```

* DB Migration
```bash
php artisan migrate
```

## Run

* Start service
```bash
php artisan serve
```

* Start npm
```bash
npm run dev
```
